# 雷神加速器自动暂停助手

这是一个 Windows 托盘小程序，用 C# WinForms 和 Visual Studio 2022 开发。它可以检测配置好的游戏进程，并在游戏全部退出后自动暂停雷神加速器时长；也可以选择在游戏启动时自动恢复时长、开机自动启动，以及关机或注销时自动暂停时长。

## 使用方法

1. 使用 Visual Studio 2022 打开根目录下的 `LeiGodAutoPause.sln`。
2. 将 `LeiGodAutoPause` 设为启动项目，按 `F5` 运行。
3. 点击“添加游戏 exe”，选择实际运行的游戏程序。需要选择游戏本体进程，不要只选择启动器，除非启动器会一直跟游戏同时运行。
4. 保持勾选“游戏全部退出后自动暂停时长”。
5. 按需设置“退出后延迟”。默认延迟 15 秒，用于避免游戏短暂重启或加载器切换时误暂停。
6. 点击“开始监控”。程序关闭窗口后会留在系统托盘继续运行。

## 自动化逻辑

- 程序每隔指定秒数检查一次游戏进程。
- 配置的游戏全部退出后，程序会等待设定延迟，再次确认没有游戏在运行，然后发送暂停请求。
- 如果启用了“游戏启动时自动恢复时长”，程序检测到游戏启动后会先恢复时长。
- 启用“开机自动启动”后，程序会写入当前用户的开机启动项，并带 `--startup` 参数缩到托盘运行。
- 启用“关机或注销时自动暂停时长”后，程序会在 Windows 结束会话时尝试发送一次最多 3 秒的暂停请求。
- 暂停和恢复请求使用本机雷神客户端日志中的当前登录会话。程序不会保存账号密码、登录令牌或请求密文。

## 注意事项

- 程序使用雷神客户端本机接口和接口日志，雷神客户端更新后接口可能变化，需要相应调整。
- 使用前请先启动并登录雷神加速器，让本机日志中包含最新登录信息。
- “游戏启动时自动恢复时长”默认关闭，避免误恢复你已经手动暂停的时长。
- 重新编译前请确认系统已安装 `.NET 8 SDK` 和 Visual Studio 2022 的“.NET 桌面开发”工作负载。

## 直接运行

已生成单文件发布版：`LeiGodAutoPause.exe`。运行前需要系统安装 .NET 8 Desktop Runtime。

## 编译输出

- Debug：`src\LeiGodAutoPause\bin\Debug\net8.0-windows\LeiGodAutoPause.exe`
- Release：使用 Visual Studio 的“生成 > 发布”，或执行 `dotnet publish src\LeiGodAutoPause\LeiGodAutoPause.csproj -c Release`。
